# DeskLink v1.0.1

DeskLink v1.0.1 是一次以 **Windows 可用性、安装体验、发布可信度准备和中文 Web UI** 为核心的修复版本。

## 重点变化

### Windows 新增 `DeskLink.exe` 图形化管理器

Windows 发布包不再只提供偏开发用途的 `desklink-agent.exe` 和 `desklink-service.exe`。

新增用户入口：

- `DeskLink.exe` — Windows 被控端设置与安装管理器；
- 双击后可直接填写信令服务器、设备 ID、访问码、STUN/TURN；
- 生产部署还可填写 Signal Token API、TURN Credential API 和 `dc2` 设备凭证；
- 自动复制 Agent / Service 到 `%ProgramFiles%\DeskLink`；
- 自动安装并重新启动 DeskLink Windows Service；
- 可查看当前 Service 运行状态。

`DeskLink.exe` 使用原生 Win32 实现，不引入 Electron/.NET 等额外运行时。

### 修复 Windows Service 配置不能立即生效的问题

v1.0.0 的安装脚本将连接参数写入机器级环境变量。Windows Service 由 SCM 启动，机器环境变量更新后不适合作为需要立即刷新生效的 Service 配置通道。

v1.0.1 改为：

- 将非敏感参数写入 `HKLM\SYSTEM\CurrentControlSet\Services\DeskLink\Environment`；
- 每次 Service 重新启动时重新加载；
- 修改配置后不再要求重启 Windows；
- 清理旧版遗留的 DeskLink machine environment 参数，降低新旧配置冲突风险。

无人值守 Access Code 和设备长期凭证仍不会放入普通环境变量，而是继续使用 Windows machine-scope DPAPI 加密保存到 `%ProgramData%\DeskLink`。

### Windows EXE 产品信息

`DeskLink.exe`、`desklink-agent.exe` 和 `desklink-service.exe` 开始写入标准 Windows VERSIONINFO，包括：

- 产品名；
- 文件说明；
- 文件版本；
- 产品版本；
- 原始文件名。

这让发布物更接近正式 Windows 应用，而不是没有产品元数据的开发构建。

### Authenticode 正式签名发布链路

Release CI 已加入可选 Authenticode 签名流程，可对以下文件统一签名并验证：

- `DeskLink.exe`；
- `desklink-agent.exe`；
- `desklink-service.exe`。

仓库管理员配置受 Windows 信任的 OV/EV 代码签名证书后，Release 工作流会在压缩 Windows ZIP 前使用 SHA-256 + RFC3161 时间戳完成签名。

> 重要：如果仓库没有配置受信任的代码签名证书，Windows 仍可能显示“未知发布者 / Windows 已保护你的电脑”。SmartScreen 信任不能通过修改程序代码伪造；正式消除此类提示需要有效 Authenticode 证书与发布信誉。

GitHub Actions Secrets：

- `WINDOWS_SIGNING_CERT_BASE64`
- `WINDOWS_SIGNING_CERT_PASSWORD`
- `WINDOWS_SIGNING_TIMESTAMP_URL`（可选）

### Web 控制端中文 UI 重构

连接首页进行了产品化调整：

- 连接状态中文化；
- 设备 ID / 访问码等输入项中文化；
- 主连接操作更突出；
- 保留最近连接设备快捷入口；
- 明确提示 Direct P2P 优先、TURN 自动兜底；
- 调整卡片、状态、输入框、按钮和空状态视觉层级；
- 优化窄屏和移动浏览器布局；
- 远程连接后仍进入沉浸式全屏工作台，不让首页 UI 占用远程画面空间。

### Release / Packages 改进

- GitHub Release 发布过程改为幂等：Release 已存在时更新说明并覆盖上传新版资产，而不是直接失败；
- Release Windows ZIP 会包含新的 `DeskLink.exe`；
- GitHub Packages 已支持发布 `ghcr.io/zerlinpi/desklink-signal` 容器镜像；
- Signal 镜像提供版本、`latest` 和 commit SHA 标签。

## Windows 发布包

`desklink-windows-v1.0.1-x64.zip` 包含：

- `DeskLink.exe` — 推荐使用的图形化入口；
- `desklink-agent.exe` — 实时采集 / 编码 / WebRTC / 输入核心；
- `desklink-service.exe` — 无人值守 LocalSystem Service；
- `install-service.ps1` — 自动化/管理员脚本安装；
- `uninstall-service.ps1` — 卸载；
- Windows 使用说明与 Service 技术文档。

## 使用前必须知道

DeskLink 当前仍然是 **自部署远程控制项目**，不是由本仓库免费提供公共中继和信令基础设施的 SaaS 服务。

Windows 被控端至少需要能访问一个已经部署的 DeskLink Signal 服务。跨公网、复杂 NAT 或严格网络环境下，应同时部署 TURN。只下载 Windows EXE、但没有任何可访问的 DeskLink Signal 服务时，客户端无法凭空完成公网设备发现和会话协商。

建议公网部署：

- HTTPS / WSS；
- 自建 coturn；
- Direct P2P 优先；
- TURN UDP 优先，TCP/TLS 兜底；
- `dc2` 独立设备凭证；
- 短期 Signal / TURN 凭证；
- 长随机 Access Code。
